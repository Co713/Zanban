# 攒班 ZanBan

像打车一样约附近的课：兴趣课与学业课就近成班，一次一付，满员开课。

当前仓库是可运行的 **演示版 SPA + FastAPI 后端**，覆盖学生端发现/课卡/成长树、老师端工作台，以及短信登录、微信扫码、高德地图定位等能力。

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 发现课 | 按类型、科目、距离、年级筛选；地图标点；定位后按真实距离排序筛选 |
| 学生课卡 | 校园卡式充值（多充多送），上课余额扣款；充值不计积分 |
| 成长树 | 实际上课扣款累计积分，可兑换礼物（演示） |
| 老师端 | 工作台 / 我的班（演示数据） |
| 登录 | 手机验证码（阿里云短信，未配置时本地回显验证码）、微信扫码（需开放平台） |
| 地图 | 高德 JS API 真实地图 + 定位；未配置 Key 时仍可用示意地图 |

## 技术栈

- 前端：原生 HTML / CSS / JavaScript（单页）
- 后端：FastAPI + SQLite（登录用户）
- 第三方：阿里云短信、微信开放平台网站应用、高德地图 Web 端 JS API

## 快速开始

### 环境要求

- Python 3.10+
- 现代浏览器（需允许定位才能使用「重新定位」）

### 安装与启动

```powershell
cd 攒班
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

编辑 `.env` 后启动：

```powershell
uvicorn server.main:app --reload --host 127.0.0.1 --port 8000
```

浏览器打开：http://127.0.0.1:8000

> 请通过上述地址访问，不要直接用本地文件打开 `index.html`（否则无法读取后端配置与地图 Key）。

### 最小可跑配置

不填任何第三方 Key 也能启动演示：

- 短信：联调模式，获取验证码后会在接口/页面回显
- 地图：示意底图；浏览器若授权定位，仍会尝试按坐标重算距离

生产或完整体验请按下方配置。

## 环境变量

复制 `.env.example` 为 `.env`（已在 `.gitignore` 中，勿提交密钥）：

| 变量 | 用途 |
| --- | --- |
| `PUBLIC_BASE_URL` | 对外访问根地址（微信回调依赖） |
| `JWT_SECRET` | JWT 密钥，上线务必更换 |
| `CORS_ORIGINS` | 跨域来源，本地可用 `*` |
| `ALIYUN_*` | 阿里云短信真实发码 |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` | 微信网站应用扫码登录 |
| `AMAP_KEY` / `AMAP_SECURITY_JS_CODE` | 高德 Web 端（JS API）地图与定位 |

更细的配置步骤见 [AUTH.md](./AUTH.md)。

## 使用提示

1. 登录后选择 **学生** 或 **老师** 身份，界面会分流。
2. 学生端点「学业课」或学业科目时会出现 **年级** 筛选。
3. 「课卡」可充值；「我的课」余额充足时用课卡支付。
4. 发现页点 **重新定位**，地图会居中到当前位置（需浏览器定位权限 + 高德 Key）。

## 开发说明

- 课程列表示例数据在 `app.js` 中，便于演示筛选与地图标点。
- 课卡余额与流水保存在浏览器 `localStorage`（按用户区分）。
- 修改 `.env` 后若未使用 `--reload`，请重启 uvicorn，否则配置不会生效。
- 高德 Key 类型须为 **Web端(JS API)**，并配置安全密钥与域名白名单（本地加 `127.0.0.1`）。
